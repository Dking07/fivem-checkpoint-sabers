## DESCRIPTION
 
Custom glowing race checkpoint saber props for FiveM, inspired by the new race props from NoPixel V. Built to mark checkpoints on any race track or street race setup with high visibility and modern racing aesthetics.

The pack includes **6 color variations**, ready to be spawned and used with any prop spawner, racing script, or map builder.
 
## Props
 
### Checkpoint sabers — `dking_checksaber_*`
 
6 color variations · **417 KB each**
 
| Model name | Color |
|---|---|
| `dking_checksaber_b` | Blue |
| `dking_checksaber_g` | Green |
| `dking_checksaber_p` | Pink |
| `dking_checksaber_r` | Red |
| `dking_checksaber_w` | White |
| `dking_checksaber_y` | Yellow |
 
## Features
 
- Inspired by the race checkpoint props from NoPixel V
- 6 color variations to match any race event aesthetic or track lighting
- Lightweight file size (**417 KB each**) for minimal streaming overhead
- **Collision is only present on the central bar** — the saber light beams have no collision, allowing vehicles to pass through or props to be placed closely without collision bugs
- **Toggleable collision**: Static collision can be completely disabled via script using the native `SetEntityCollision(entity, false, false)`
- **Textures in .ytd**: Saber textures are contained in the `.ytd` file (Note: changing textures will not alter the light/emissive color)
